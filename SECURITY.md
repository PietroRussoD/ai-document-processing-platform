# Security Policy

This pre-1.0 portfolio project is a local demo for synthetic documents. It is
not supported for production or sensitive data. Only the current `main` branch
is considered for fixes; tagged releases have no security maintenance promise.

## Reporting a Vulnerability

Do not publish exploit details, credentials or real document contents in an
issue or pull request. If GitHub offers **Report a vulnerability** for this
repository, use it. Otherwise, if you have repository access, open an issue
requesting a private contact channel without including vulnerability details.
Share the affected version, impact and a minimal synthetic reproduction only
after a private channel is established. There is no response-time guarantee.

See [Local Security and Limitations](docs/security-and-limitations.md) for the
demo's trust boundaries and known gaps.

# v0.8.0

These are candidate release notes. `v0.8.0` is not tagged yet.

## Scope

This version makes the local document-processing demo easier to run, inspect
and maintain. It does not turn the platform into a production deployment.

## Included

- Dry-run-first, bounded retention of terminal document records and their
  database-owned evidence. Active and review-required documents are excluded.
- Report-only inventory of possible orphaned published blobs and old staged
  upload files. Files are never deleted by this command.
- Non-root API and console images, with the API's locked runtime dependencies
  and English Tesseract OCR; unused system `pip` is removed from the API image.
- An opt-in Compose `processing` profile for PostgreSQL, Temporal, API,
  dispatcher, worker and the operator console.
- A clean-checkout verification script, Python and frontend package SBOMs,
  local final-image inventory and vulnerability-scan instructions, Gitleaks CI,
  Dependabot where supported, and a vulnerability-reporting policy.

## Verification

On 2026-09-26, commit `41f45fa` passed the clean-checkout gate: 395 backend
tests (88.14% coverage), 62 frontend tests (93.8% statement coverage), static
checks, frontend build and package SBOM exports. An isolated Compose stack
processed a synthetic PDF through the console to `REVIEW_REQUIRED`. Final-image
SBOMs and HIGH/CRITICAL scans were inspected for that commit.

The subsequent `73f3d7c` change removed runtime `pip`. Its image builds, the
API imports, Alembic starts, and real Tesseract OCR reads a synthetic PDF.

The final candidate commit `54fce56` passed the clean-checkout gate again:
395 backend tests (88.14% coverage), 62 frontend tests (93.8% statement
coverage), static checks, frontend build and package SBOM exports. An isolated
Compose stack processed a synthetic PDF through the console to
`REVIEW_REQUIRED`. Final-image CycloneDX 1.5 SBOMs inventoried 275 API and
86 console packages. Trivy 0.74.0 reported 1 CRITICAL and 76 HIGH package
findings for the API (34 distinct IDs), and zero HIGH/CRITICAL findings for
the console. These are package findings, not a count of distinct exploitable
paths. [CI for this commit](https://github.com/PietroRussoD/ai-document-processing-platform/actions/runs/36221420555)
passed. Before tagging, require green CI for the commit containing these
updated notes and explicitly accept the local-demo image risk.

## Limits

This is a local fixture for synthetic documents. Most endpoints and Temporal
UI have no user authentication; there is no TLS, tenant isolation, parser
sandbox, malware scan or application-encrypted storage. Known API-image
vulnerabilities remain, including findings in `libxml2` and Tesseract. Do not
upload untrusted or confidential files or expose the stack publicly. See
[security and limitations](../security-and-limitations.md).

Physical blob deletion, external storage, production identity and managed
deployment remain out of scope. The `/api/v1` namespace is unchanged.

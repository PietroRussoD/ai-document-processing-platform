# v1.0.0

A local-first demonstration of document extraction, validation and operator
review using synthetic documents. This is not a production deployment.

## Included

- Bounded PDF upload, local blob storage and PostgreSQL-backed document records.
- Durable Temporal processing with embedded-text extraction, Tesseract OCR
  fallback and deterministic classification and invoice validation.
- An operator console for processing outcomes, human review, corrections,
  controlled reprocessing and protected source-PDF preview.
- Optional local Ollama proposals for invoice fields. Proposals remain advisory;
  operators verify and explicitly adopt corrections.
- Prometheus metrics, structured logs, correlation IDs, a Grafana dashboard and
  a static architecture System Map.

## Limits

Use synthetic, non-sensitive documents on a local machine only. Most endpoints
and Temporal UI are unauthenticated; there is no TLS, tenant isolation, parser
sandbox or malware scanning. See [security and limitations](../security-and-limitations.md).

Repository visibility and verification of the exact release commit remain open.
Do not tag or publish this candidate until both are complete. The `/api/v1`
namespace is unchanged.

# v1.2.0 - Local Security Boundaries

Status: in development, unreleased.

Python and API metadata report `1.2.0.dev0`; the operator console reports
`1.2.0-dev.0`. The latest tagged release is
[v1.1.0](v1.1.0.md).

## Target Scope

This cycle will strengthen the local-only security boundary and assess a
single-operator access model for document APIs. The planned work begins with a
CI check that ensures published Compose ports remain bound to `127.0.0.1`.
Access-control changes will be included only after their route coverage and
local secret handling are defined.

PDF parser isolation is a separate, more substantial design and implementation
track. Include it in this release only if a credible, reproducible boundary is
chosen and its failure behavior can be verified. This release does not target
public hosting, real documents, multiple users or production readiness.

## Verification

Release scope and verification evidence are pending. Update this draft as work
is completed; before release, record only implemented behavior and the limits
of its verification, then replace development versions with `1.2.0`.

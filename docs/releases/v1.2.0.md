# v1.2.0 - Local Security Boundaries

Status: in development, unreleased.

Python and API metadata report `1.2.0.dev0`; the operator console reports
`1.2.0-dev.0`. The latest tagged release is
[v1.1.0](v1.1.0.md).

## Target Scope

This cycle strengthens the local-only security boundary with a CI check that
ensures published Compose ports remain bound to `127.0.0.1` and a single local
operator token for document APIs. Route coverage, local secret handling and
the browser token flow have been implemented and verified.

PDF parser isolation is a separate, more substantial track. The design review
found that the current Compose setup does not provide a per-document job
boundary without adding a separately operated runtime; this work is deferred
from v1.2.0. See [PDF parser isolation design](../security/pdf-parser-isolation-design.md).
This release does not target public hosting, untrusted or real documents,
multiple users or production readiness.

## Verification

Release scope and verification evidence are pending. Update this draft as work
is completed; before release, record only implemented behavior and the limits
of its verification, then replace development versions with `1.2.0`.

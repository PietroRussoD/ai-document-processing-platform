# v0.9.0 - System Map and Demo Walkthrough

This is a local portfolio demonstration for synthetic documents, not a
production deployment or a service for untrusted uploads.

## Scope

This version makes the implemented architecture and a real document-processing
path easier to inspect. The System Map is a static explanation of persisted
states and component responsibilities, not live tracing.

## Included

- A System Map covering the console, API, dispatcher, Temporal, worker,
  PostgreSQL, local blob volume and text-extraction components, with links to
  implementation evidence and technical references.
- Reference journeys for automatic invoice approval, review-required invoices
  and terminal failure followed by controlled reprocessing.
- A deterministic synthetic PDF walkthrough that prints a direct console URL
  for the uploaded document, plus a local-only desktop/mobile browser check.

## Limits

Most endpoints and Temporal UI are unauthenticated. There is no TLS, tenant
isolation, parser sandbox, malware scan or application-encrypted storage. Do
not upload confidential or untrusted documents or expose the stack publicly.
See [security and limitations](../security-and-limitations.md). The browser
checks do not establish formal WCAG conformance.

The `/api/v1` namespace is unchanged. No live trace, hosted demo or public
deployment is included.

Trivy 0.74.0 with its downloaded vulnerability database. HIGH and CRITICAL

used as a clean result.

All API findings are Debian system packages; a single CVE can appear against
several binary packages. The report provides no fixed versions for these
findings. Their applicability and proposed mitigations are now documented in
the [API image CVE triage](v1.1-image-cve-triage.md). The findings remain open;
the clean Python/JavaScript advisory results do not cover operating-system
packages.

For example, Trivy classifies libxml2 CVE-2026-6653 as CRITICAL. The
[Debian security tracker](https://security-tracker.debian.org/tracker/CVE-2026-6653)
lists the installed trixie version as vulnerable but annotates it as a minor
issue without a DSA. Scanner severity is therefore not treated as a confirmed
application exploit or as a substitute for distribution-specific triage.

JSON reports remain under ignored
`artifacts/release-check-20261015-ui/{api,console}-cves.json`. Runtime SBOMs are
under ignored `artifacts/`. The temporary image archives were removed after
inspection; the scanned image tags remain available locally.

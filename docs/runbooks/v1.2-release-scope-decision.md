# v1.2 Release Scope and Risk Decision

Prepared on 2026-10-18 for the v1.2.0 candidate. Pietro confirmed applying
the bounded local-demo scope to this release on 2026-10-18.

## Confirmed Release Scope

Release the source and documentation as a local portfolio demo using only
synthetic, non-sensitive PDFs. Keep published Compose ports bound to
`127.0.0.1` and retain the shared local operator-token boundary. Public source
availability does not authorize public hosting of the running backend.

Do not use confidential or untrusted documents, host the backend publicly, or
distribute the API runtime image. Keep parser isolation as a separate future
track. This release does not claim production readiness, per-user authorization,
tenant isolation, comprehensive accessibility conformance, or physical-mobile
validation.

## Evidence and Residual Risk

| Item | Evidence | Decision |
| --- | --- | --- |
| API image packages | The fresh 2026-10-18 Trivy 0.74.0 scan found 33 distinct CVEs across 75 HIGH and one CRITICAL Debian package associations. No HIGH/CRITICAL Python-package findings were reported. See [v1.2 image review](../security-and-limitations.md#v12-image-review). | Accepted only for the local synthetic-data demo. Findings remain open; this is not an image distribution or public-hosting approval. |
| Console image package | The initial cached image had one HIGH `CVE-2026-77214` finding in `libexpat`; a clean rebuild installed the fixed `2.9.0-r0` package and the final scan reported no HIGH/CRITICAL findings. | Keep the clean-build result in the verification record. |
| Operator authentication | Document API routes require one shared local token. Health, metrics, OpenAPI and Temporal UI are unauthenticated inside the loopback boundary. The token is not a user, role or tenant system. | Accept this boundary only within the local single-operator demo. |
| Parser and document trust | No disposable parser sandbox is implemented. PDF/OCR processing still uses application containers and their aggregate resource budgets. | Synthetic PDFs only; hostile inputs and confidential documents remain out of scope. |
| Browser verification | Compose smoke processing passed. Playwright document flow passed at desktop and mobile-emulation viewports. Other fixture-driven demo scenarios and physical-device checks were not run for this candidate. | Record the exact checks and do not claim broader browser, AI-provider or device validation. |

This is a scoped decision for v1.2.0. It does not state that the API image is
free of vulnerabilities or safe for untrusted inputs, public exposure, or
distribution.

## Release Gate

The exact final commit must pass GitHub Actions. Final version metadata and the
release notes must match that commit before Pietro creates the v1.2.0 tag or
publishes the release.

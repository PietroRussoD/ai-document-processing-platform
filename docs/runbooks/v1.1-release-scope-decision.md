# v1.1 Release Scope and Risk Decision

Prepared on 2026-10-17 against HEAD
`84feba40bcbc378673909c09cd15ec43748fc4ea`. Pietro confirmed the proposed
scope and physical-device-check deferral on 2026-10-17. This records a bounded
local-demo risk decision; it does not finalize or publish the release.

## Proposed Scope

Release the source and documentation as a local portfolio demo using only
synthetic, non-sensitive PDFs. Keep published Compose ports on loopback and
retain the existing local bearer-token boundary. Public source availability
does not authorize public hosting of the running backend.

Carry forward the v1.0 restriction against distributing the API runtime image
as a release artifact. Keep all scanner findings visible. New inputs, network
exposure, image distribution or changes to parser/model configuration require
a new assessment.

## Evidence and Residual Risk

| Item | Evidence | Proposed disposition |
| --- | --- | --- |
| Image packages | The 2026-10-16 ARM64 API scan reported 33 distinct CVEs across 75 HIGH and one CRITICAL package associations, including CVE-2026-6653. No fixed version was listed in that scan. | Accepted only within the local synthetic-input boundary. Findings remain open. This does not state today's package-fix availability. |
| Native PDF/OCR parsing | Page/pixel/text limits and non-root application containers with resource budgets, dropped capabilities and no-new-privileges were verified. Disposable per-document parser isolation and a read-only runtime filesystem remain unimplemented. | Retain as follow-ups for the local demo. Untrusted-document or public-service use requires a separate security design and verification. |
| Resource recovery | Normal processing, oversized OCR failure and worker stop/restart recovery were checked. Load, OOM and PID exhaustion recovery were not tested. | Describe the budgets as local-demo limits; make no capacity or exhaustion-recovery claim. |
| Desktop accessibility and PDFs | Installed Safari workflows and native PDF rendering were checked; Pietro reported working page/PDF zoom, review/PDF keyboard checks and VoiceOver on the review page. | Retain the recorded scope. No comprehensive screen-reader audit or WCAG conformance claim. |
| Physical mobile devices | Two Chromium touch-emulation scenarios passed for digital/scanned review at 390 × 844 and resized landscape 844 × 390. Physical PDF gestures, on-screen keyboard and OS-specific behavior were not tested. | Physical-device checks deferred for this local release; retain them as unverified and avoid claiming physical-mobile support was validated. |
| Real Ollama inference | The latest ordinary backend/runtime verification used AI disabled. Earlier AI work has its own evidence. | Keep a fresh real-model run optional and separately tracked; make no new inference-quality claim. |

The backend checkpoint passed 615 tests with 89.82% coverage. Earlier frontend
verification recorded 166 tests and 35 Storybook browser scenarios. Changes
between the backend checkpoint commit and the HEAD above concern documentation.
These results do not establish parser safety or correct vulnerable libraries.

## Decision Recorded - 2026-10-17

Pietro confirmed the local synthetic-data scope and deferral of physical-device
checks. The v1.1 image findings are accepted only within this boundary. This
does not extend to untrusted documents, public hosting, API image distribution
or a claim of physical-mobile validation. The v1.0 decision did not
automatically extend to v1.1. Version finalization and release-note
consolidation remain a separate next step. Commits, tags and publication remain
Pietro's actions.

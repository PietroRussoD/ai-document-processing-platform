# v0.1 Verification Runbook

This runbook verifies the implemented `v0.1` ingestion scope from a clean
checkout. It intentionally does not claim to verify asynchronous processing:
accepted documents remain associated with a `QUEUED` processing run until the
`v0.2` worker milestone.

## Prerequisites

- Docker Desktop or a compatible Docker daemon;
- Python 3.13 and `uv`;
- Node.js 24 and pnpm 11.23.

## Start the Local Stack

From the repository root, install the locked backend dependencies and start
PostgreSQL:

```bash
uv sync --all-groups --locked
docker compose up -d postgres
uv run alembic upgrade head
```

Wait until `docker compose ps postgres` reports a healthy service, then start
the API in one terminal:

```bash
uv run uvicorn document_platform.bootstrap:app --reload
```

Start the console in another terminal:

```bash
cd apps/operator-console
pnpm install --frozen-lockfile
pnpm dev
```

The API is available at `http://localhost:8000`; the console is available at
`http://localhost:5173` and proxies `/api` to the API by default.

## Verify the Happy Path

1. Confirm liveness:

   ```bash
   curl --fail-with-body http://localhost:8000/health/live
   ```

   The response is `{"status":"UP"}`.

2. In the console, select a valid, unencrypted PDF smaller than 20 MiB and
   submit it. The console must show a document identifier, a processing-run
   identifier, document status `UPLOADED` and run status `QUEUED`.

3. Copy the document identifier and confirm the persisted projection:

   ```bash
   curl --fail-with-body http://localhost:8000/api/v1/documents/<document-id>
   ```

4. Verify idempotent replay directly with a local valid PDF. Run the following
   request twice without changing either the file or the idempotency key:

```bash
curl --request POST http://localhost:8000/api/v1/documents \
  --header 'Idempotency-Key: v0-1-verification-001' \
  --form 'document=@<path-to-pdf>;type=application/pdf'
```

The first request returns `202 Accepted` with `replayed: false`; the second
returns `202 Accepted` with `replayed: true`. Reusing the same key for different
content returns `409 Conflict` with an RFC 9457 problem response.

## Verify Quality Gates

Run the backend checks from the repository root:

```bash
uv run ruff check .
uv run ruff format --check .
uv run pyright
uv run pytest
```

Run the frontend checks:

```bash
cd apps/operator-console
pnpm check
```

The backend test command enforces at least 85% branch coverage and writes local
reports to `htmlcov/index.html` and `coverage.xml`. The frontend command checks
OpenAPI type drift, formatting, linting, TypeScript, tests with coverage and the
production build.

## Expected Limitations

- No worker executes queued processing runs yet.
- No OCR, structured extraction, review queue, authentication or notifications
  are included.
- Storage and PostgreSQL credentials are intentionally local-development only.
- PDF structural validation is not malware scanning or hostile-file isolation.

Stop local services when finished:

```bash
docker compose down
```
